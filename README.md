# 🏛️ 01 — Gebze Dijital

**Municipal Citizen Services Platform**

A Flutter-based mobile platform designed to bring municipal services and citizen interactions together in one application.

### Key Features

- Municipal news and announcements
- Planned water and electricity interruptions
- On-duty pharmacies
- Parking information
- Citizen requests and suggestions
- Local places and city guide
- Emergency information
- Gebze Pati animal services
- Firebase-powered backend infrastructure

### Technology Stack

`Flutter` `Dart` `Firebase` `Firestore`

**Project Status:** In Development
